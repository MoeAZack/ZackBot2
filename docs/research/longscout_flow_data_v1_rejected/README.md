# Daily flow acquisition rejected before economic testing

All166 symbol histories had to reconcile with pinned native hourly OHLCV. Native daily candles failed this gate; no data release, no V98 economic trial and no excluded/repaired coin. Failed attempt and raw-response hashes are preserved. Two sampled mismatch days (BONK/FLOKI) had identical native1h OHLCV on all24hours but different native1d v/qv totals; this motivates a separately frozen native-hourly acquisition, not relaxed tolerances. Planned V98 financial hypotheses remain unchanged and locked.
